# 科技坦克大战 · 网页小游戏技术文档

> 面向对象：solo builder（独立开发者单兵实现）
> 技术栈：HTML5 Canvas + 原生 ES6 + CSS3 + Web Audio API，**无构建工具**，双击 `index.html` 即可运行。
> 本文档约定：所有数值均为建议初值，集中在 `config.js`，便于统一调参。

---

## 0. 文档定位

本文档描述一款「科技（赛博朋克 / 霓虹未来）风格」的俯视角多人坦克对战网页游戏，支持单人 vs AI、双人、三人及双人联手战人机。AI（人机）具备**自主寻路、追击、预判射击、自动躲避、寻找最佳攻击点位、拾取道具/装备**的能力。

阅读顺序建议：
1. 先读 §1~§3 理解游戏是什么、怎么赢；
2. 再读 §4~§5 了解文件结构与全局参数；
3. 按 §6~§14 逐模块实现；
4. §15 按里程碑推进，§16 做交付验收。

## 1. 项目概述

### 1.1 游戏定位
- 一款**本地对战**（单人 vs AI / 双人 / 三人同屏）的竞技坦克大战：玩家在同一竞技场内对战 AI 或彼此。
- 结合市面上爆火的多人坦克玩法（竞技场对抗 + 道具/装备争夺 + 障碍掩体 + 击杀计分 + 强势 AI BOSS）。
- 视觉走**科技霓虹风**：深色网格战场、发光描边、粒子特效、屏幕震动、HUD 全息质感。

### 1.2 核心体验
- 移动 —— 坦克前后移动 + 原地转向（炮塔朝向随移动方向 / 或独立瞄准）。
- 射击 —— 发射子弹，命中扣除对方护甲/血量。
- 掩体 —— 战场上分布可破坏与不可破坏障碍，提供走位策略。
- 增益道具 —— 随机刷新，改变战局（加速、护盾、连发、冰冻、隐身、回血）。
- 武器掉落 —— 地图随机掉落限时装备（追踪导弹、激光、散弹、地雷、穿墙子弹），持续 15 秒后自动消失。
- AI —— 会主动锁定并攻击玩家，具备自动躲避、寻找最佳攻击点位、寻路与拾取道具/装备等行为。

### 1.3 技术目标
- 全部运行于浏览器，无后端、无依赖。
- 60 FPS 稳定运行，Canvas 自适应分辨率。
- 代码模块化、低耦合，方便 solo builder 迭代与维护。

## 3. 游戏模式与胜利条件

入场流程：**进入界面（开始游戏 / 操作说明）→ 选择模式 → 战斗 → 结算**。

### 3.1 四种模式

| 模式 | 参战单位 | 队伍 | 视角 |
| --- | --- | --- | --- |
| 单人挑战 | 1 人类 vs 1 AI | 敌对 | 单屏全景 |
| 双人对战 | 2 人类 | 各自为战 | 单屏全景 |
| 三人混战 | 3 人类 | 各自为战 | 单屏全景（可缩放） |
| 双人联手战人机 | 2 人类 vs 1 AI BOSS | 玩家结盟 | 单屏全景 |

### 3.2 胜利 / 失败条件

| 模式 | 胜利条件 | 失败条件 |
| --- | --- | --- |
| 单人挑战 | 击败 AI（击杀 1 次或打空其血量，见 §10） | 被 AI 击杀 |
| 双人对战 | 时间结束前击杀对方达 N 次（默认 5），或时间到时击杀数更高 | 被先击杀 N 次 |
| 三人混战 | 规定时间（默认 120s）结束得分最高 | 得分垫底 |
| 双人联手战人机 | 联手击败 AI BOSS（BOSS 血量见 §10） | 两名玩家全部阵亡 |

> 混战计分：击杀 +100，被击杀 -20，拾取道具 +10。兜底规则：若开局 30 秒内无正面接触，AI 会主动把玩家向中心牵引（可选）。

### 3.3 复活规则
- 玩家阵亡后 `respawnDelay`（默认 3s）在安全出生点复活，短暂无敌（默认 2s，闪烁表现）。
- 单人挑战：玩家阵亡即判负（不复活）；AI 视难度可配置是否复活（默认不复活）。
- 双人联手战人机模式：任一玩家存活即可继续，二人同时阵亡判负。

## 5. 全局配置 `config.js`

建议结构（示例）：

```js
export const CONFIG = {
  // 画布与物理
  canvas: { width: 1280, height: 720 },
  tick: 1000 / 60,                    // 固定逻辑步长（毫秒）

  // 地图（默认 1280x720 竞技场，四周封闭）
  world: { width: 1280, height: 720 },
  tiles: 40,                          // 单体格子像素，用于对齐障碍

  // 坦克基础属性
  tank: {
    size: 36,                       // 边长（碰撞盒）
    speed: 160,                     // 移动速度 px/s
    rotateSpeed: 180,               // 转向速度 度/s
    maxHp: 100,
    armor: 0,                       // 减伤
    fireCooldown: 600,              // 射击间隔 ms
    invincibleTime: 2000,           // 复活无敌 ms
  },

  // 子弹
  bullet: { speed: 420, radius: 5, damage: 20, life: 2000 },

  // AI BOSS
  boss: { maxHp: 600, speed: 140, fireCooldown: 800, ... },

  // 增益道具
  powerup: { spawnInterval: 6000, maxCount: 4, ... },

  // 限时武器掉落（装备）
  weapon: {
    dropInterval: 8000, maxCount: 3, lifetime: 15000, useDuration: 15000,
    missile: { speed: 320, turnRate: 3.0, life: 3000, damage: 50, cooldown: 900 },
    laser:   { range: 900, damage: 40, beamMs: 100, cooldown: 1200 },
    spread:  { pellets: 3, spreadAngle: 30, damage: 18, speed: 420, cooldown: 700 },
    mine:    { damage: 80, placeCooldown: 1000, maxCount: 3, triggerRadius: 28, mineLife: 20000 },
    pierce:  { damage: 30, speed: 480, cooldown: 550 },
  },

  // 键盘映射（见 §7）
  keys: { ... },

  // 计分
  score: { kill: 100, death: -20, pickup: 10, winKills: 5, roundTime: 120 },
};
```

> 所有魔数一律写成 `CONFIG` 字段，禁止硬编码散落各处。

## 6. 核心架构

### 6.1 游戏循环（main.js）

采用「固定时间步长 + 渲染插值」保证不同刷新率手感一致：

```js
let last = performance.now(), acc = 0;
function loop(now) {
  acc += now - last; last = now;
  while (acc >= CONFIG.tick) {           // 固定步长逻辑更新
    update(CONFIG.tick / 1000);
    acc -= CONFIG.tick;
  }
  render(acc / CONFIG.tick);             // 渲染（可带插值）
  requestAnimationFrame(loop);
}
```

`update(dt)` 顺序：**输入 → AI → 坦克移动 → 子弹 → 增益道具 → 武器掉落 → 碰撞 → 死亡判定 → 计分/胜负 → 特效/音效更新**。
`render()`：清屏 → 网格背景 → 障碍 → 增益道具 → 武器掉落 → 坦克 → 子弹 → 粒子 → HUD → 屏幕震动偏移。

### 6.2 场景状态机（scene.js）

场景基类统一接口，主循环只调用当前场景：

```js
class Scene { enter(){}; exit(){}; update(dt){}; render(ctx){}; }
```

| 场景 | 职责 |
| --- | --- |
| `MenuScene` | 进入界面：开始游戏、操作说明 两个主按钮 |
| `ControlsScene` | 操作说明（键位表 + 玩法简介），可返回 |
| `ModeSelectScene` | 四种模式选择卡片 |
| `GameScene` | 核心战斗，创建地图/坦克/AI/道具 |
| `GameOverScene` | 结算（胜负/得分排行 + 再来一局） |

### 6.3 实体系统（entity.js）

所有可运动/可碰撞物体继承 `Entity`：

```js
class Entity {
  constructor(x, y) { this.x = x; this.y = y; this.vx = 0; this.vy = 0; this.dead = false; }
  update(dt) {}
  render(ctx) {}
  getRects() { return []; }   // 返回碰撞盒列表，供碰撞检测
}
```

派生：`Tank`、`Bullet`、`Powerup`、`Particle`。维护一个 `entities` 数组统一更新/渲染/清理（`dead` 标记延迟删除）。

## 7. 输入系统（input.js）

### 7.1 设计要点
- 用 `Set` 记录当前按下按键，`keydown/keyup` 更新，**不用** `key.repeat`。
- 阻止方向键/空格等默认滚动行为（`preventDefault`）。
- 提供 `isDown(code)` / `consumePress(code)`（用于「按下瞬间」触发一次，如射击、技能）。

### 7.2 默认键位（集中在 config.js，可改）

| 玩家 | 移动 | 射击 | 技能（加速） |
| --- | --- | --- | --- |
| P1 | `W A S D` | `F` | `G` |
| P2 | `↑ ← ↓ →` | `L` | `K` |
| P3 | 小键盘 `8/4/5/6` | 小键盘 `0` | 小键盘 `+` |
| P3 备选 | `I/J/K/L` | `H` | `U`（笔记本无小键盘时） |

```js
keys: {
  p1: { up:'KeyW', down:'KeyS', left:'KeyA', right:'KeyD', fire:'KeyF', skill:'KeyG' },
  p2: { up:'ArrowUp', ... fire:'KeyL', skill:'KeyK' },
  p3: { up:'Numpad8', ... fire:'Numpad0', skill:'NumpadAdd' },
}
```

> 键位冲突/键盘「鬼影」（多键同按无法识别）属硬件限制，选用上表已尽量规避；文档第六章「操作说明」界面需展示同一张表。

## 8. 地图与碰撞（map.js / collision.js）

### 8.1 地图结构
- 竞技场尺寸 `world.width × world.height`，四周为不可破坏边界。
- 内部障碍按格子（`tiles=40px`）摆放，便于对称设计与复用。
- 网格背景：Canvas 绘制半透明网格线，营造科技感。

### 8.2 地图布局示意

默认竞技场 1280×720（网格 32 列 × 18 行，每格 40px）。按分区规划，兼顾对称与走位：

```
+-------------+-------------+-------------+
|   左上区     |   中上区     |   右上区     |
|  出生点 P1  |  钢/砖混合   |  出生点 AI   |
+-------------+-------------+-------------+
|   左翼       |  中心交战区  |   右翼       |
|  草丛·(潜伏) |  空旷+装备   |  草丛·(潜伏) |
+-------------+-------------+-------------+
|   左下区     |   中下区     |   右下区     |
|  出生点 P3  |  钢/砖混合   |  出生点 P2   |
+-------------+-------------+-------------+
```

实现用字符网格描述（`map.js` 常量数组，一行一字符串）：

| 字符 | 含义 |
| --- | --- |
| `#` | 钢铁墙（不可破坏掩体） |
| `B` | 砖墙（可破坏，耐久数） |
| `·` | 草丛（可进入，半透明） |
| `.` | 空地（可走、可刷新道具/装备） |

分区设计要点：
- **出生点**沿四角/四边分散（单人模式 AI 出生在对角），避免开局贴脸。
- **钢铁墙**集中布置在中轴与四角，形成不可破坏的战略掩体。
- **砖墙**成簇分布，可被拆穿开路，动态改变地形。
- **草丛**藏在两翼，供坦克潜伏/偷袭。
- **中心空旷区**为高风险交战区，吸引玩家与 AI 争夺；增益道具与武器装备优先在此刷新。

### 8.3 障碍类型

| 类型 | 可破坏 | 子弹可穿过 | 说明 |
| --- | --- | --- | --- |
| 钢铁墙 `STEEL` | 否 | 否 | 固定掩体，科技蓝白发光 |
| 砖墙 `BRICK` | 是（多次） | 否 | 被打中减少耐久，耐久 0 消失 |
| 草丛 `BUSH` | 否 | 是 | 坦克可进入，隐藏于其中（半透明） |
| 水域/边界 `BOUND` | 否 | 否 | 仅作边界，不可进入 |

### 8.4 碰撞检测
统一用 **AABB（轴对齐包围盒）**；坦克用「旋转后重置为包含盒」或「圆形 + 矩形」简化：

```js
function aabb(a, b) {
  return a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y;
}
```

碰撞解析优先级：
1. 坦克 × 边界/障碍 → 回退本帧位移（按轴分别处理，先 X 后 Y 避免卡角）。
2. 子弹 × 障碍 → 命中砖墙扣耐久/消失，命中钢铁墙消失。
3. 子弹 × 坦克 → 判伤害（含护甲减伤与无敌状态）。
4. 坦克 × 道具 → 拾取生效。

> 移动采用「轴分离」：先沿 X 移动并检测，再沿 Y 移动并检测，可有效避免滑入障碍。

## 9. 坦克与战斗系统（tank.js / bullet.js）

### 9.1 坦克属性
`hp / maxHp、armor、speed、fireCooldown、invincible、team、ai(标记)`。

### 9.2 移动与朝向
- 移动方向由「当前按下的方向键合成向量」决定；坦克朝向平滑转向该向量。
- 提供两种瞄准模式（二选一，默认 A，更贴合键盘操作）：
  - **A 炮口随移动方向**：简单，适合同屏混战。
  - **B 炮口可独立瞄准**（鼠标或第二套键）：操作更精细，可选实现。

### 9.3 射击
- 按下射击键（`consumePress`）进入冷却，生成 `Bullet`，初速度 = 坦克朝向方向 × `bullet.speed` 加上坦克当前速度（可选）。
- 子弹有生命周期 `life`（默认 2s），到期或命中即销毁，命中时产生粒子 + 屏幕震动。

### 9.4 伤害结算
```js
function dealDamage(target, dmg) {
  if (target.invincible) return;
  const real = Math.max(0, dmg - target.armor);
  target.hp -= real;
  if (target.hp <= 0) onKill(target);
}
```

### 9.5 坦克外观设计（绘制规范）

> 目标：告别「小方格」粗糙感，用**分层矢量绘制 + 圆角/渐变/发光 + 动态细节**塑造精良的科技坦克。全部程序化 Canvas 绘制，不依赖外部图片。

#### 9.5.1 设计原则（反例 vs 正例）

| 维度 | ❌ 粗糙做法 | ✅ 目标 |
| --- | --- | --- |
| 造型 | 单一纯色方块 / 小圆点 | 分层结构：履带→车体→炮塔→炮管→能量核心 |
| 轮廓 | 直角矩形 | 圆角 + 倒角，避免死板直角 |
| 质感 | 纯色填充 | 渐变明暗 + 发光描边 + 金属高光线条 |
| 朝向 | 固定不转 | 炮塔/炮管随朝向平滑旋转 |
| 动态 | 静止 | 履带滚动、开火后坐、受伤闪白、引擎粒子、无敌闪烁 |

#### 9.5.2 队伍配色（霓虹主色）

| 单位 | 主色 | 车体底色 | 说明 |
| --- | --- | --- | --- |
| P1 | 霓虹青 `#00e5ff` | `#0d1420` | 默认高亮青 |
| P2 | 品红 `#ff2ec8` | `#140f1e` | 高亮品红 |
| P3 | 霓虹绿 `#3cff8f` | `#0e1412` | 高亮绿 |
| AI / BOSS | 警示橙 `#ff9f00` | `#16100a` | 狂暴阶段渐变为红 `#ff2e2e` |

#### 9.5.3 分层结构与几何参数（相对碰撞盒 36px）

| 层序 | 部件 | 形状 | 尺寸/位置 | 材质/颜色 |
| --- | --- | --- | --- | --- |
| 1 | 底盘阴影 | 椭圆 | 42×36，向下偏移 4px | 半透明黑 `rgba(0,0,0,0.35)` |
| 2 | 履带 ×2 | 圆角矩形 | 宽 9px、长 38px，中心距 ±16px | 深黑 `#0a0f18` + 主色描边 + 白色纹齿 |
| 3 | 车体 | 圆角矩形 | 26×34，圆角 6px | 主色纵向渐变（上亮下暗） |
| 4 | 车体装饰 | 发光斜切线/散热格栅 | 车体前缘 | 主色 + `shadowBlur=8` |
| 5 | 炮塔 | 圆 | 半径 9px | 主色填充 + 深色描边 |
| 6 | 炮管 | 圆角矩形 | 4×18px，沿朝向伸出 | 深灰 `#0d1420` + 主色炮口 |
| 7 | 能量核心 | 圆 | 半径 3.5px | 白色 + 主色呼吸发光 |

#### 9.5.4 动态效果
- **履带滚动**：纹齿沿移动方向按累计位移循环滚动（`treadOffset += speed*dt` 取模回卷），速度越快滚动越快。
- **炮塔/炮管转向**：随 `tank.angle` 平滑旋转（与移动或瞄准一致）。
- **开火后坐**：射击瞬间炮管沿朝向回缩 3px，0.1s 内复位。
- **受伤闪白**：受击时车体叠加白色高亮 0.1s（`globalAlpha` 淡出）。
- **引擎粒子**：移动时车尾每帧喷 1~2 个淡蓝/灰粒子。
- **无敌闪烁**：复活无敌期车体 alpha 在 0.4↔1 之间 5Hz 闪烁。
- **BOSS 阶段变色**：BOSS 血量阶段切换时主色渐变 + 边框脉冲。

#### 9.5.5 绘制伪代码（tank.js render）

```js
function drawTank(ctx, tank) {
  ctx.save();
  ctx.translate(tank.x, tank.y);

  // 1. 底盘阴影
  ctx.fillStyle = 'rgba(0,0,0,0.35)';
  ellipse(ctx, 0, 4, 21, 18);

  // 2. 左右履带（含滚动纹齿）
  drawTrack(ctx, -16, 0, tank.treadOffset, tank.color);
  drawTrack(ctx,  16, 0, tank.treadOffset, tank.color);

  // 3. 车体（纵向渐变 + 发光描边）
  const hull = ctx.createLinearGradient(0, -17, 0, 17);
  hull.addColorStop(0, lighten(tank.color, 0.25));
  hull.addColorStop(1, darken(tank.color, 0.45));
  roundRect(ctx, -13, -17, 26, 34, 6);
  ctx.fillStyle = hull; ctx.fill();
  ctx.shadowColor = tank.color; ctx.shadowBlur = 8;
  ctx.strokeStyle = tank.color; ctx.lineWidth = 1.5; ctx.stroke();

  // 4. 炮塔 + 炮管（朝 tank.angle 旋转，含后坐）
  ctx.save();
  ctx.rotate(tank.angle);
  const recoil = tank.recoil;                        // 开火后坐偏移，0.1s 衰减
  roundRect(ctx, -2, -18 - recoil, 4, 18, 2);        // 炮管
  ctx.fillStyle = '#0d1420'; ctx.fill();
  ctx.beginPath(); ctx.arc(0, 0, 9, 0, Math.PI * 2); // 炮塔
  ctx.fillStyle = tank.color; ctx.fill();
  ctx.restore();

  // 5. 能量核心（呼吸发光）
  ctx.shadowColor = tank.color; ctx.shadowBlur = 12;
  ctx.beginPath(); ctx.arc(0, 0, 3.5, 0, Math.PI * 2);
  ctx.fillStyle = '#ffffff'; ctx.fill();
  ctx.shadowBlur = 0;
  ctx.restore();
}

function drawTrack(ctx, x, y, offset, color) {
  ctx.save(); ctx.translate(x, y);
  roundRect(ctx, -4.5, -19, 9, 38, 4.5);
  ctx.fillStyle = '#0a0f18'; ctx.fill();
  ctx.strokeStyle = color; ctx.lineWidth = 1; ctx.stroke();
  ctx.strokeStyle = 'rgba(255,255,255,0.25)';        // 纹齿滚动
  for (let d = -17 + (offset % 6); d < 19; d += 6) {
    ctx.beginPath(); ctx.moveTo(-4.5, d); ctx.lineTo(4.5, d); ctx.stroke();
  }
  ctx.restore();
}
```

#### 9.5.6 实现要点
- 封装 `roundRect()` / `ellipse()` 工具函数（`ctx.roundRect` 在部分浏览器需 Polyfill）。
- 发光成本高：战斗中每帧为每个坦克开 `shadowBlur`，若坦克较多可把静态发光层用 `OffscreenCanvas` 离屏缓存，保证 60FPS。
- 所有颜色从 `tank.color` 派生（`lighten/darken` 工具函数），禁止硬编码，便于统一换配色。

## 10. 人机 AI 设计（ai.js）

### 10.1 总体方案
AI 采用**有限状态机（FSM）**，每帧根据场景状态切换：

```
        ┌────────────┐
        │  PATROL 巡逻│
        └─────┬──────┘
    视野内玩家? │
   ┌──────────┴──────────┐
   ▼                      ▼
┌─────────┐          ┌─────────┐
│ SEEK_PU │ 拾取道具  │  CHASE  │ 追击
└─────────┘          └────┬────┘
                          │ 进入射程 & 有射击角度
                          ▼
                     ┌─────────┐
                     │ ATTACK  │ 攻击（预判射击）
                     └────┬────┘
                      被子弹瞄准? ▲
                          │      └─ 脱离威胁
                          ▼
                     ┌─────────┐
                     │  EVADE  │ 规避子弹
                     └─────────┘
```

### 10.2 各状态职责
| 状态 | 行为 |
| --- | --- |
| `PATROL` | 沿预设路径/随机waypoint移动，索敌 |
| `CHASE` | 朝最近玩家移动，用寻路绕过障碍 |
| `ATTACK` | 计算提前量后射击；相机抖动、特效表现 |
| `EVADE` | 检测来袭子弹，垂直于威胁方向闪避 |
| `SEEK_POWERUP` | 视野内有道具/装备且自身血量/火力不足时拾取 |
| `REPOSITION`   | （强化 AI/BOSS）评估战场点位，移动到最佳攻击位 |

### 10.3 核心算法
**障碍规避 + 寻路**：推荐在障碍格子上做**简版 A\***（每 `repathInterval`=300ms 重算一次），成功率与性能都稳；简单的图（障碍少于 60 格）足够快。若想更轻量，可用「射线检测 + 沿障碍切线绕行」的 steering 方案。

**预判射击（前置量）**：
```js
// 预测目标子弹飞行 ts 后位置，向该点射击
const ts = dist / CONFIG.bullet.speed;
const aimX = target.x + target.vx * ts;
const aimY = target.y + target.vy * ts;
this.rotateTo(atan2(aimY - this.y, aimX - this.x));
```

**规避判定**：检测朝向自己的、距离低于阈值且时间碰撞（TOI）临近的子弹，向垂直于子弹方向且靠近掩体的一侧移动。

### 10.4 人机 BOSS 难度曲线
「双人联手战人机」模式的 AI 为 BOSS：
- 基础属性见 §5 `boss`（血量高、火力强）。
- 分阶段：血量 >60% 常规进攻；40%~60% 提升射速；<40% 进入**狂暴**（移动+射速提升、加入散射）。
- 每阶段切换播放警示音效 + 视觉变色，营造 BOSS 战体验。

### 10.5 双人联手战人机 AI 强化
该模式的 BOSS 使用强化版 FSM，在基础 AI（§10.1~§10.3）之上额外具备：
- **自动躲避（主动规避弹幕）**：不只绕开单发子弹，而是汇总所有来袭子弹，计算每条子弹的「时间碰撞（TOI）」并构建弹幕威胁场，选择「垂直偏移 + 靠近掩体」的最优闪避向量；面对两路交叉火力时，沿威胁场梯度逃生。
- **寻找最佳攻击点位（REPOSITION）**：周期性对战场做可达点采样，为每个候选点评分：
  - 视野分：能否直线命中至少一名玩家（无障碍遮挡）；
  - 掩体分：是否被钢铁墙包围、开火后能否迅速退入掩体；
  - 侧翼分：是否位于玩家阵型侧翼/背面（降低被反击概率）；
  - 距离分：与最近玩家距离是否落在自身有效射程内。
  选综合分最高的点作为下一目标，用 A* 移动到位后再进入 `ATTACK`。
- **集火与走位分离**：面对两名结盟玩家，优先绕后击杀血量低/无护盾者，避免被交叉火力夹击。

### 11.1 增益道具（powerup.js）

| 装备 | 效果 | 说明 |
| --- | --- | --- |

### 11.3 追踪导弹与激光：弹道与碰撞伪代码

关键参数（集中在 `config.js`，便于平衡调整）：

| 武器 | 伤害 | 冷却时间 | 射程/射速 | 弹道特征 |
| --- | --- | --- | --- | --- |
| 追踪导弹 `MISSILE` | 50 | 900ms | 320px/s | 追踪转向 3.0 rad/s，最长存活 3000ms |
| 激光 `LASER` | 40 | 1200ms | 900px | 瞬发、无飞行时间、贯穿 |

> 平衡依据：默认炮伤害 20、冷却 600ms；两件强力武器单发更强但冷却更长，配合 15s 限时形成爆发窗口。

#### 11.3.1 追踪导弹 `MISSILE`
弹道特征：**有飞行时间的弹道体**，每帧以最大转向速度朝最近敌方平滑转向；碰撞即爆炸（不穿透）。

```js
class Missile extends Bullet {
  constructor(x, y, angle, shooter, team) {
    super(x, y, angle, shooter, team);
    this.speed = CONFIG.weapon.missile.speed;       // 飞行速度 px/s
    this.turnRate = CONFIG.weapon.missile.turnRate; // 最大转向弧度/秒
    this.life = CONFIG.weapon.missile.life;         // 最长存活 ms，超时自毁
    this.target = null;
  }

  update(dt) {
    this.target = this.acquireTarget();      // 目标死亡则重新锁定最近敌方
    if (this.target) {
      const desired = Math.atan2(this.target.y - this.y, this.target.x - this.x);
      this.angle = steer(this.angle, desired, this.turnRate * dt); // 限制转向
    }
    this.x += Math.cos(this.angle) * this.speed * dt;
    this.y += Math.sin(this.angle) * this.speed * dt;
    this.life -= dt * 1000;

    if (this.hitTank()) {                   // 命中坦克 → 爆炸
      dealDamage(this.hit, CONFIG.weapon.missile.damage); // 伤害 50
      spawnExplosion(this.x, this.y);
      this.dead = true;
    } else if (this.hitWall()) {            // 命中障碍 → 爆炸（不穿透）
      spawnExplosion(this.x, this.y);
      this.dead = true;
    } else if (this.life <= 0) {            // 超时自毁
      this.dead = true;
    }
  }

  acquireTarget() {
    return nearestEnemy(this.x, this.y, this.team); // 最近非己方坦克，无则 null
  }
}

// 平滑转向：cur 朝 target 最多转动 maxStep 弧度
function steer(cur, target, maxStep) {
  const diff = normalizeAngle(target - cur);
  return cur + clamp(diff, -maxStep, maxStep);
}
```

> 拾取追踪导弹时 `tank.fireCooldown = CONFIG.weapon.missile.cooldown`（900ms）；15s 到期恢复默认 600ms。

#### 11.3.2 激光 `LASER`
弹道特征：**瞬发、无飞行时间**，用射线（线段）判定；**可贯穿钢铁墙与任意数量目标**（区别于「穿墙子弹」的飞行穿透）。

```js
const LASER = CONFIG.weapon.laser; // { range:900, damage:40, beamMs:100, cooldown:1200 }

function fireLaser(shooter) {
  const start = { x: shooter.x, y: shooter.y };
  const dir = { x: Math.cos(shooter.angle), y: Math.sin(shooter.angle) };
  const hits = [];

  // 1) 收集射线上的所有敌方坦克（激光不因障碍截断，故不做墙体采样）
  for (const t of allTanks) {
    if (t.team === shooter.team) continue;
    if (segmentIntersectsCircle(start, dir, LASER.range, t)) hits.push(t);
  }

  // 2) 按距离从近到远排序，依次造成伤害（贯穿多目标）
  hits.sort((a, b) => distSq(shooter, a) - distSq(shooter, b));
  for (const t of hits) {
    dealDamage(t, LASER.damage);
    spawnSparks(t.x, t.y); // 命中火花
  }

  // 3) 渲染发光直线 + 末端光斑，beamMs 后消失
  spawnBeam(start, dir, LASER.range, LASER.beamMs);
}

// 线段与圆（坦克碰撞盒简化为圆）的相交检测
function segmentIntersectsCircle(start, dir, len, circle) {
  const ox = circle.x - start.x, oy = circle.y - start.y;
  let t = ox * dir.x + oy * dir.y;      // 圆心在射线方向上的投影长度
  t = clamp(t, 0, len);
  const px = start.x + dir.x * t;       // 圆心到射线的最近点
  const py = start.y + dir.y * t;
  const dx = circle.x - px, dy = circle.y - py;
  return dx * dx + dy * dy <= circle.r * circle.r;
}
```

> 拾取激光时 `tank.fireCooldown = CONFIG.weapon.laser.cooldown`（1200ms）；15s 到期恢复默认 600ms。

#### 11.3.3 散弹 `SPREAD`
弹道特征：一次性扇形射出 3 发子弹，每发独立判定碰撞，用于近战压制。

```js
function fireSpread(shooter) {
  const pellets = CONFIG.weapon.spread.pellets;       // 弹丸数 3
  const spread = CONFIG.weapon.spread.spreadAngle;    // 总扇形角 30°
  const step = spread / (pellets - 1);
  const base = shooter.angle - spread / 2;

  for (let i = 0; i < pellets; i++) {
    spawnBullet(shooter.x, shooter.y, base + step * i, {
      speed: CONFIG.weapon.spread.speed,              // 420 px/s
      damage: CONFIG.weapon.spread.damage,            // 每颗 18
      life: 1600,
    });
  }
  spawnMuzzleFlash(shooter, shooter.angle);           // 枪口扇形火花
}
// 冷却：tank.fireCooldown = CONFIG.weapon.spread.cooldown（700ms）
```

#### 11.3.4 地雷 `MINE`
弹道特征：放置延时爆炸物，敌方坦克进入触发半径即引爆（区域封锁/陷阱）。

```js
class Mine extends Entity {
  constructor(x, y, team) {
    super(x, y);
    this.team = team;
    this.r = CONFIG.weapon.mine.triggerRadius;        // 触发半径 28
    this.life = CONFIG.weapon.mine.mineLife;          // 自身存活 20000ms
    this.armed = false;                               // 布防中（先闪烁提示）
  }

  update(dt) {
    if (this.life <= 0) { this.dead = true; return; }
    this.life -= dt * 1000;
    if (!this.armed && this.life <= CONFIG.weapon.mine.mineLife - 800) this.armed = true; // 0.8s 后进入待爆
    if (this.armed) {
      for (const t of allTanks) {
        if (t.team === this.team) continue;
        if (distSq(this, t) <= this.r * this.r) this.explode(t);
      }
    }
  }

  explode(tank) {
    dealDamage(tank, CONFIG.weapon.mine.damage);      // 伤害 80
    spawnExplosion(this.x, this.y);
    this.dead = true;
  }
}

// 放置：携带地雷期间，每次按下射击键在坦克身后放置一枚（placeCooldown 1000ms，同屏上限 3）
function placeMine(shooter) {
  if (mineCount(shooter.team) >= CONFIG.weapon.mine.maxCount) return;
  addEntity(new Mine(
    shooter.x - Math.cos(shooter.angle) * 40,
    shooter.y - Math.sin(shooter.angle) * 40,
    shooter.team
  ));
}
```

#### 11.3.5 穿墙子弹 `PIERCE`
弹道特征：高速飞行的弹道体，碰撞时**跳过障碍判定**，直接穿过砖墙/钢铁墙/草丛，命中坦克才结算。

```js
class PierceBullet extends Bullet {
  constructor(x, y, angle, shooter, team) {
    super(x, y, angle, shooter, team);
    this.speed = CONFIG.weapon.pierce.speed;          // 480 px/s（更快）
    this.life = 2000;
  }

  update(dt) {
    this.x += Math.cos(this.angle) * this.speed * dt;
    this.y += Math.sin(this.angle) * this.speed * dt;
    this.life -= dt * 1000;

    if (this.hitTank()) {                             // 命中坦克结算伤害
      dealDamage(this.hit, CONFIG.weapon.pierce.damage); // 30
      this.dead = true;
    }
    // 关键：不调用 hitWall()，障碍视为透明，直接穿墙
    if (this.life <= 0) this.dead = true;
  }
}
// 冷却：tank.fireCooldown = CONFIG.weapon.pierce.cooldown（550ms）
```

> 差异小结：`LASER` 是即时命中判定（一次性穿透多目标）；`MISSILE` 是追踪弹道 + 命障即爆；`SPREAD` 是扇形多发普通弹；`MINE` 是放置型范围陷阱；`PIERCE` 是飞行弹道但障碍透明（跳过墙体碰撞）。

### 11.4 武器视听表现：音效与视觉特效

所有音效由 `audio.js` 用 Web Audio API 程序化合成（综合说明见 §12.3），视觉特效由 `particles.js`/`camera.js` 实现。以下给出可直接落地的具体合成参数与渲染参数。

#### 音效合成参数（Web Audio）

| 武器 | 发射音 | 持续/飞行音 | 命中/引爆音 |
| --- | --- | --- | --- |
| 追踪导弹 `MISSILE` | 锯齿波 400→120Hz 下扫，0.25s，增益 0.4→0 | 正弦+锯齿 60Hz 低频叠加 6Hz 颤音循环，增益 0.15（随距离衰减，可 3D 定位） | 白噪声 0.5s + 正弦 80→30Hz 下行，增益 0.6→0，低通 1000→200Hz |
| 激光 `LASER` | 方波 1000→4000Hz 上扫，0.12s，增益 0.3→0 | —（瞬发无持续） | 高频噪声 0.08s + 带通共振 3500Hz，增益 0.2 |
| 散弹 `SPREAD` | 3 路白噪声同步 0.08s + 正弦 150Hz 底鼓，增益 0.5→0 | — | 同普通子弹命中（短促「啵」） |
| 地雷 `MINE` | 方波 800Hz 金属咔哒 0.03s + 正弦 1200Hz 上膛哔 0.05s | — | 白噪声 0.6s + 正弦 60Hz 巨响，增益 0.7→0 |

## 12. 特效与音效

### 12.1 粒子特效（particles.js）
- 射击枪口火花、子弹拖尾光带、爆炸粒子、护盾碎裂、拾取光环。
- 实现：粒子数组（位置 + 速度 + 生命 + 颜色 + 大小衰减），`render` 用 `globalCompositeOperation='lighter'` 叠加发光。
- 统一在 `ParticleSystem` 管理，单次爆炸约 spawn 20~40 粒子。

### 12.2 屏幕震动（camera.js）
- `shake(intensity, duration)`，渲染时对画布施加随机偏移并衰减。
- 射击轻微、命中中等、爆炸/击杀强烈。

### 12.3 音效（audio.js）
- Web Audio 合成：射击（短方波下扫）、爆炸（噪声 + 低通衰减）、拾取（上行音）、受伤（短锯齿）、击杀（双音上行）。
- 提供全局静音开关。

function update(dt) {

### 14.2 坦克移动（轴分离 + 碰撞）
```js
tank.move(dt) {
  const dir = normalize(输入向量);
  this.faceAngle = lerpAngle(this.faceAngle, atan2(dir.y, dir.x), dt * rotateSpeed);
  const sp = this.speed * (boost ? 1.5 : 1);
  this.x += dir.x * sp * dt;  resolveCollisionX();  // 撞墙回退 X
  this.y += dir.y * sp * dt;  resolveCollisionY();  // 撞墙回退 Y
}
```

### 14.3 AI 主循环
```js
ai.update(dt) {
  this.perceive();                    // 收集最近玩家/子弹/道具/障碍信息
  this.state = this.transition();     // FSM 状态迁移（见 §10.1）
  switch(this.state){
    case 'PATROL':       this.patrol(dt); break;
    case 'CHASE':        this.chase(dt); break;
    case 'ATTACK':       this.attack(dt); break;   // 含预判射击
    case 'EVADE':        this.evade(dt); break;
    case 'SEEK_POWERUP': this.seekPowerup(dt); break;
    case 'REPOSITION':   this.reposition(dt); break;   // 仅强化 AI/BOSS
  }
}
```
