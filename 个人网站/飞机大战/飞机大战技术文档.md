# 飞机大战网页小游戏 — 技术设计文档

> 版本：v1.0
> 目标：一份可直接交给「Builder（代码生成 Agent）」实现的技术文档。
> 定位：竖版滚动、科幻霓虹风格、玩法多样、含多阶段大 Boss 的飞机大战射击游戏。
> 运行要求：纯前端，无构建步骤，浏览器打开即可玩。

---

## 1. 项目概述

一款科幻风格的竖版卷轴射击游戏。玩家操控战机在屏幕底部移动，躲避并击落从上方出现的敌机与弹幕，收集道具强化火力，最终击败多阶段大 Boss。

**核心体验目标：**
1. 画面美观、科技感强（霓虹光效、粒子、发光弹幕）。
2. 玩法多样（多武器、道具、连击、大招、多类敌机、多阶段 Boss）。
3. 有压迫感且华丽的 BOSS 战。

---

## 2. 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 语言 | HTML5 + Canvas 2D + 原生 JavaScript (ES6) | 无需依赖库 |
| 渲染 | `<canvas>` 单画布 | 游戏画面全部绘制在 canvas 上 |
| UI | DOM + CSS3 覆盖层 | 菜单、HUD、结算界面用 HTML/CSS 更易做漂亮效果 |
| 资源 | 全部程序化绘制 | **不依赖外部图片**，用 Canvas 渐变/路径/光效绘制所有图形 |
| 音效 | Web Audio API（可选） | 无音频文件时用振荡器合成音效 |

**备选方案：** 若 Builder 熟悉 Phaser 3，可用 Phaser 实现，但下述数据结构与玩法逻辑保持不变。

**优点：** 打开即玩、易验证、无资源加载问题、便于后续迭代。

## 4. 全局设计

### 4.1 画布与坐标系
- 画布逻辑分辨率固定，例如 **480 × 720**（竖屏），用 CSS 等比缩放适配窗口。
- 原点在左上角，x 向右、y 向下。
- 玩家在屏幕下方（y ≈ 620），敌机从顶部（y < 0）出现向下方移动。

```js
// config.js 示例
const GAME = {
  W: 480,
  H: 720,
  FPS: 60,
};
```

### 4.2 游戏状态机

```js
const STATE = {
  MENU:     'menu',
  PLAYING:  'playing',
  PAUSED:   'paused',
  LEVEL_CLEAR: 'level_clear',
  GAMEOVER: 'gameover',
};
```

- 主循环 `update(dt)` 仅当 `state === PLAYING` 时更新游戏逻辑；其余状态更新 UI。

## 5. 核心玩法系统

### 5.1 玩家战机（player.js）

**属性：**

```js
player = {
  x, y,                 // 中心坐标
  speed: 300,           // 移动速度 px/s
  hp: 100, maxHp: 100,
  power: 1,             // 火力等级 1~5
  shield: 0,            // 护盾值（抵挡伤害次数）
  energy: 0, maxEnergy: 100,   // 大招能量
  invincible: 0,        // 受伤后无敌时间（秒）
  weapon: 'normal',     // 副武器类型: none/missile/laser
};
```

**输入与移动：**
- 键盘：方向键 + WASD 移动；`Shift` 或 `J` 释放大招；`K` 或 `空格` 放炸弹；`P` 暂停。
- 鼠标/触屏：按住拖动战机（战机跟随指针并做平滑插值）。

**移动实现要点：** 位置按 `dt` 更新并 clamp 到屏幕内；鼠标模式用 `lerp` 平滑跟随。

**受伤：**
- 被敌弹/敌机命中：若有 `shield > 0`，扣除护盾；否则扣 `hp`，进入 0.5s 无敌闪烁（半透明闪烁）。
- `hp <= 0` → 播放爆炸 → `GAMEOVER`。

### 5.2 武器系统（bullet.js + player.js）

**火力等级决定主武器形态：**

| 等级 | 形态 | 说明 |
|------|------|------|
| 1 | 单发直线弹 | 每秒约 6 发 |
| 2 | 双发并列 | 两路平行弹 |
| 3 | 三发散射 | 中间直线 + 两侧小角度 |
| 4 | 五发扇形 | 更宽散射 |
| 5 | 强化扇形 + 副武器 | 弹速/伤害提升，副武器同发 |

**副武器（道具获得，持续一段时间）：**
- `missile`：追踪导弹，自动锁定最近的敌机。
- `laser`：穿透激光，贯穿整列敌人。

**子弹数据结构：**

```js
bullet = {
  owner: 'player' | 'enemy',
  x, y, vx, vy,
  damage: 10,
  radius: 4,
  color: '#00ffff',
  type: 'normal' | 'missile' | 'laser' | 'enemy',
  life: 5,             // 存活时间（秒），防止无限飞出
  pierce: false,       // 是否穿透
};
```

### 5.3 敌机（enemy.js）

**类型分类：**

| 类型 | 血量 | 行为 | 得分 |
|------|------|------|------|
| 小兵 | 1~2 | 直线下冲 | 10 |
| 俯冲机 | 3 | 快速俯冲后定住 | 20 |
| 横移机 | 4 | 左右摆动前进，发射单发子弹 | 30 |
| 精英怪 | 30~60 | 慢速，发射扇形弹幕 | 150 |

**敌机通用结构：**

```js
enemy = {
  type, x, y, vx, vy,
  hp, maxHp,
  radius,
  shootTimer,          // 射击冷却
  pattern,             // 移动/弹幕模式标识
  score,
  color,
};
```

- 敌机进入屏幕后激活；飞出屏幕底部或左侧/右侧一定距离则移除。

### 5.4 Boss 战（boss.js）

**Boss 通用结构：**

```js
boss = {
  x, y,                 // 中心
  hp, maxHp,
  radius,               // 碰撞半径
  phase: 1,             // 当前阶段
  phases: [ { hpRatio: 0.66 }, { hpRatio: 0.33 } ], // 阶段阈值
  entering: true,       // 入场动画
  patternTimer,
};
```

**Boss 流程：**
1. **预警阶段：** Boss 出现前 3 秒，屏幕显示红色「WARNING」闪烁提示，同时有警报音。
2. **入场动画：** Boss 从顶部缓慢下降到固定高度（y ≈ 180），期间无敌。
3. **战斗阶段：** 根据血量切换到不同阶段，切换时短暂无敌并全屏清弹（bullet clear）。

**弹幕模式（多阶段变化，越战越强）：**

| 模式 | 说明 |
|------|------|
| 扇形散射 | 以 Boss 为中心向玩家方向发射 N 发扇形弹 |
| 环形弹幕 | 360° 均匀发射一圈/多圈 |
| 螺旋弹幕 | 发射角度随时间旋转，形成螺旋 |
| 追踪弹 | 发射瞄准玩家的慢速追踪弹 |
| 扫射激光 | 预判一条瞄准线，延迟后发射粗激光 |

**实现建议：**
- 用弹幕类型枚举 + 定时器驱动；每个阶段组合 1~2 种弹幕。
- Boss 被击败 → 大爆炸 + 掉落大量道具/分数 → 进入 `LEVEL_CLEAR`。

### 5.5 道具系统（powerup.js）

**掉落规则：** 敌机/Boss 被击落时有概率掉落道具，从敌机位置向下飘落。

| 图标标识 | 名称 | 效果 |
|---------|------|------|
| S | 火力强化 | 火力等级 +1（上限 5） |
| M | 追踪导弹 | 副武器变为导弹，持续 10s |
| L | 穿透激光 | 副武器变为激光，持续 10s |
| B | 炸弹 | 立即清屏全灭敌机与敌弹 |
| ❤ | 回血 | 恢复 20 点血量 |
| ★ | 分数倍率 | 10s 内分数 ×2 |

**道具结构：**

```js
powerup = {
  x, y, type,   // 'power' | 'missile' | 'laser' | 'bomb' | 'heal' | 'score'
  vy: 80,       // 下落速度
  radius: 14,
};
```

### 5.6 连击与能量（Combo / Energy）

- 连续击破敌机（间隔 < 2s）累计 `combo`，combo 提升分数倍率。
- 攻击命中敌机累积 `energy`；能量满后可手动释放大招。

**大招：** 全屏清弹 + 对全场敌人造成大量伤害 + 满屏粒子特效，持续约 2 秒。

### 5.7 关卡与波次（wave.js）

- 用**波次（wave）**驱动敌机生成，随时间推进难度递增。
- 波次配置示例：

```js
const WAVES = [
  { spawns: [ ['small', 5], ['dive', 3] ], interval: 1.0, boss: false },
  { spawns: [ ['small', 8], ['side', 4], ['elite', 1] ], interval: 0.8, boss: false },
  { boss: true, bossType: 'boss_1' },
  // ... 后续波次递增
];
```

- 每 3 波出现一个 Boss；Boss 波前清空普通敌机。

## 6. 视觉风格（科技风）

**整体基调：** 深色星空背景 + 霓虹发光元素 + 高纯度青/品红/紫色。

**背景（background.js）：**
- 多层视差滚动：深色渐变底色 + 滚动网格 + 星空粒子（近大远小、速度不同）。
- 网格线使用低透明度线段，营造未来感。

**光效技巧：**
- 使用 `ctx.shadowBlur` + `shadowColor` 实现霓虹发光。
- 战机尾部添加拖尾粒子（每帧生成 2~3 个小光点）。
- 爆炸使用粒子系统：随机速度的光点 + 渐隐 + 缩放。

**配色建议：**

| 元素 | 颜色 |
|------|------|
| 玩家战机 | 青色 `#00e5ff` |
| 玩家子弹 | 亮青 / 白 |
| 敌机 | 品红 `#ff2d78` / 橙 |
| 敌弹 | 橙红 / 品红 |
| Boss | 紫红渐变 + 高光 |
| 护盾 | 半透明蓝光圈 |

**UI 风格：**
- 菜单：全屏深色背景 + 霓虹标题（发光文字）+ 竖排按钮。
- HUD：顶部分数/波次，底部血条与能量条，科幻圆角边框。
- 结算界面：战绩统计 + 重新开始按钮。

## 8. 游戏主循环与更新顺序

```js
function loop(timestamp) {
  const dt = Math.min((timestamp - lastTime) / 1000, 0.05); // 限制最大步长
  update(dt);
  render();
  requestAnimationFrame(loop);
}

function update(dt) {
  if (state !== 'playing') return;
  handleInput(dt);       // 玩家移动/发射/技能
  updatePlayer(dt);
  updateBullets(dt);     // 玩家弹 + 敌弹（移动、碰撞、越界）
  updateEnemies(dt);     // 生成、移动、射击
  updateBoss(dt);        // Boss 逻辑与弹幕
  updatePowerups(dt);    // 下落 + 拾取
  updateParticles(dt);   // 粒子
  updateBackground(dt);  // 背景滚动
  checkCollisions();     // 所有碰撞检测
  updateWave(dt);        // 波次调度
  cleanupDeadObjects();  // 移除越界/死亡对象
}
```

## 9. 碰撞检测

- 全部使用**圆形碰撞**：比较两圆心距离与半径之和。

```js
function circleHit(a, b) {
  const dx = a.x - b.x, dy = a.y - b.y;
  const r = a.radius + b.radius;
  return dx * dx + dy * dy <= r * r;
}
```

- 玩家弹 ↔ 敌机/Boss；敌弹/敌机 ↔ 玩家；道具 ↔ 玩家。

## 10. 性能优化

1. **对象池（Object Pool）：** 子弹与粒子频繁创建销毁，用对象池复用，避免 GC 卡顿。
2. **离屏剔除：** 对象完全离开可视区即移除。
3. **粒子上限：** 全局粒子数限制（如 500），超出丢弃最旧。
4. **避免每帧创建渐变对象：** 常用渐变色在初始化时缓存。
5. **光效控制：** `shadowBlur` 开销较高，仅对关键对象（战机、Boss、子弹）启用，普通弹幕可关闭。

function fire() {

// 环形
for (let i = 0; i < 36; i++) {
